The World in One Day — a front page summing up Thursday 19 November 2026: 40 numbered stories across 6 regions, a dotted world map with numbered pins, a day-in-numbers strip, and a DATE CHECK box that keeps Wednesday's stories off the page. Lead stories: the first Trump–Xi–Putin three-way summit in Shenzhen, the ICJ's ruling on Myanmar's Rohingya case, Anthropic's record $81.3bn IPO, GTA VI's release day, COP31's final hours, and Cyclone Akvan. Every story was cross-checked against wire and broadsheet reports published that day; disputed claims are attributed, not stated as fact. The image is drawn programmatically (PIL) so every word renders crisply — no AI-generated text.

## Run it

```sh
python3 main.py
```

Writes the baked front page to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Deterministic: both runs write the same bytes.
